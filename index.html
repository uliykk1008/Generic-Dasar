Pengantar Generic

Generic adalah fitur dalam bahasa pemrograman seperti Dart yang memungkinkan kita membuat kode yang dapat digunakan untuk berbagai tipe data tanpa harus menentukan tipe secara langsung. Dengan menggunakan type parameter seperti <T>, tipe data bisa ditentukan saat kode digunakan sehingga lebih fleksibel.

Secara konsep, generic membantu membuat kode yang reusable dan menjaga type safety, sehingga kesalahan tipe data bisa dicegah sejak awal.

Manfaat Generic:

  • Kode bisa digunakan kembali (reusable)
  • Lebih aman karena type safety
  • Mengurangi duplikasi kode
  • Lebih fleksibel untuk berbagai tipe data
  • Mempermudah pengelolaan kode

Analogi sederhananya generic seperti cetakan kue yang bisa digunakan untuk berbagai rasa tanpa harus membuat cetakan baru setiap kali.

Masalah Tanpa Generic

Non Generic (Jalan)

Pada contoh ini, program masih menggunakan dynamic sehingga data bisa berupa apa saja. Selama tipe data yang dimasukkan sesuai, program tetap bisa berjalan dengan normal.

Penjelasan:

  • Program berhasil dijalankan karena data yang digunakan adalah angka
  • Tipe data tidak ditentukan sejak awal
  • Masih berisiko jika terjadi perubahan tipe data
  • Kurang aman karena tidak ada pembatasan tipe

class Box {
  dynamic data;

  Box(this.data);

  print(nilai);
}

Non Generic (Error)

Pada contoh ini, program masih menggunakan dynamic sehingga data bisa berupa tipe apa saja. Namun, hal ini bisa menyebabkan masalah ketika tipe data yang digunakan tidak sesuai.

Penjelasan:

  • Data yang dimasukkan berupa String ("halo")
  • Data tersebut dipaksa menjadi int
  • Terjadi ketidaksesuaian tipe data
  • Error baru muncul saat program dijalankan (runtime)
  • Ini menunjukkan bahwa penggunaan dynamic kurang aman

Sintaks Generic Dasar dan contoh pada class&function

Dalam generic, digunakan type parameter seperti <T>, <E>, atau <K, V> untuk mewakili tipe data yang belum ditentukan. Tipe ini baru akan diketahui saat class atau function digunakan.

Penulisan type parameter biasanya mengikuti konvensi tertentu agar lebih mudah dipahami.

Konvensi Penamaan:

  • T digunakan untuk menunjukkan tipe data secara umum
  • E biasanya digunakan untuk elemen dalam struktur data seperti list
  • K digunakan sebagai key (kunci)
  • V digunakan sebagai value (nilai)
  • R digunakan untuk tipe nilai kembalian (return)

Dengan menggunakan generic, kita dapat membuat class dan function yang lebih fleksibel karena dapat digunakan untuk berbagai jenis tipe data tanpa harus menuliskan ulang kode yang sama.

DART SOURCE CODE
// Nama   : Uliya Gumpari
// NIM   : 251410008
// Kelas : SI2A

class MyClass {
  T data;
  MyClass(this.data);

  T getData() {
    return data;
  }
}

T myFunc(T value) {
  return value;
}

void main() {
  // Class generic
  var myIntClass = MyClass(10);
  var myStringClass = MyClass('test');

  print(myIntClass.getData());
  print(myStringClass.getData());

  // Function generic
  var intValue = myFunc(100);
  var stringValue = myFunc('hello');

  print(intValue);
  print(stringValue);
}
}

Contoh Kelas Box<T>

Box<T> menyimpan data dengan tipe fleksibel.

T ditentukan saat object dibuat.

Contoh:

Box<int>(10)

Box<String>("Hello")

DART SOURCE CODE
// Nama   : Uliya Gumpari
// NIM   : 251410008

          class Box {
  T? _value; // nullable

  Box(this._value);

  T? get value => _value;

  void setValue(T value) {
    _value = value;
  }
}

void main() {
  // INT
  var intBox = Box(10);
  print('Int Box Value: ${intBox.value}');
  intBox.setValue(20);
  print('Int Box Value After Set: ${intBox.value}');

  var stringBox = Box('Hello, Generic!');
  print('String Box Value: ${stringBox.value}');
  stringBox.setValue('Hello World');
  print('String Box Value After Set: ${stringBox.value}');

  // DOUBLE
  var doubleBox = Box(3.14);
  print('Double Box Value: ${doubleBox.value}');
}

Pair<K, V>

Pair<K, V> menyimpan dua data dengan tipe berbeda.

K = tipe untuk key, V = tipe untuk value.

Contoh:

Pair<String, int> ("age", 30)

Pair<String, String> ("name", "Alice")

Intinya: fleksibel dan type-safe.

DART SOURCE CODE
// Nama   : Uliya Gumpari
// NIM   : 251410008
// Kelas : SI2A

  class Pair {
  K key;
  V value;

  Pair(this.key, this.value);

  void printPair() {
    print('Key: $key, Value: $value');
  }
}

void main() {
  // Pair dengan tipe data String dan int
  var pair1 = Pair('age', 30);
  pair1.printPair(); // Output: Key: age, Value: 30

  // Pair dengan tipe data String dan String
  var pair2 = Pair('name', 'Alice');
  pair2.printPair(); // Output: Key: name, Value: Alice

  // Pair dengan tipe data int dan double
  var pair3 = Pair(1, 2.71);
  pair3.printPair(); // Output: Key: 1, Value: 2.71
}

combine<T, U>

Fungsi generic untuk menggabungkan dua nilai dengan tipe berbeda.

T = tipe value1, U = tipe value2.

Contoh:

combine<String, int> ("Number is", 10)

combine<int, double> (10, 20.5)

Intinya: fleksibel untuk berbagai tipe data.

Type Inference (Inferensi Tipe)

Dart dapat menebak tipe generic secara otomatis dari nilai yang diberikan.

Tidak perlu menuliskan tipe secara manual.

Contoh:

myFunc(10) → int

myFunc("test") → String

Program berjalan tanpa error.

DART SOURCE CODE
// Nama   : Uliya Gumpari
// NIM   : 251410008
// Kelas : SI2A

T myFunc(T value) {
  return value;
}

void main() {
  var intValue = myFunc(10); // infer: int
  print(intValue.runtimeType); // Output: int

  var stringValue = myFunc("test"); // infer: String
  print(stringValue.runtimeType); // Output: String
}

Pembatasan Tipe dan Manfaatnya

Pembatasan tipe membantu memastikan program hanya menggunakan data yang sesuai, sehingga lebih aman dari kesalahan saat dijalankan.

Dengan tipe yang jelas, kode menjadi lebih mudah dipahami dan dibaca oleh programmer.

Pembatasan ini juga memungkinkan penggunaan fungsi atau method khusus dari tipe tertentu.

Selain itu, dapat mencegah penggunaan tipe data yang tidak sesuai dengan tujuan program.

Hal ini membantu dalam membuat struktur kode yang lebih rapi dan terarah.

Pembatasan Tipe pada Interface dan Class

Digunakan untuk membatasi tipe data pada class atau interface.

Hanya tipe tertentu yang boleh digunakan.

Generic dibatasi hanya untuk turunan dari class Animal.

  void makeSound() {

  dogCage.sound(); // Output: Woof!

  var catCage = AnimalCage(Cat());
  catCage.sound(); // Output: Meow!

Praktik 1 Sealed Class dengan Pattern Matching

Sealed class memungkinkan kita mengetahui semua kemungkinan subclass yang ada dalam satu file.

Dengan pattern matching, setiap kemungkinan tersebut dapat diperiksa dan ditangani secara spesifik sesuai jenis objeknya.

Hal ini membuat kode lebih aman karena semua kondisi dapat ditangani tanpa ada yang terlewat.

DART SOURCE CODE
// Nama   : Uliya Gumpari
// Nim    : 251410008
// Kelas  : SI2A

sealed class Status {}

class Loading extends Status {}

class Loaded extends Status {
  final String data;
  Loaded(this.data);
}

class Failed extends Status {
  final String error;
  Failed(this.error);
}

void handleStatus(Status status) {
  switch (status) {
    case Loading():
      print('Loading...');
    case Loaded(:final data):
      print('Data: $data');
    case Failed(:final error):
      print('Error: $error');
  }
}

void main() {
  print("=== SEALED PATTERN ===");

  handleStatus(Loading());
  handleStatus(Loaded("Data berhasil"));
  handleStatus(Failed("Terjadi kesalahan"));
}

Sistem State Management

State management adalah cara mengatur kondisi aplikasi seperti loading, success, dan error. Dengan sealed class, setiap state dapat didefinisikan dengan jelas.

Fitur:

  • Mengelola kondisi aplikasi
  • Mengatur alur program

Kenapa digunakan:

  • Agar kondisi aplikasi lebih terstruktur
  • Mencegah error yang tidak ter-handle

Batasan:

  • Bisa menjadi kompleks jika state terlalu banyak
DART SOURCE CODE
// Nama   : Uliya Gumpari
// Nim    : 251410008
// Kelas  : SI2A

sealed class AppState {}

class LoadingState extends AppState {}

class SuccessState extends AppState {
  final List items;
  SuccessState(this.items);
}

class ErrorState extends AppState {
  final String message;
  ErrorState(this.message);
}

void updateUI(AppState state) {
  switch (state) {
    case LoadingState():
      print('Loading...');
    case SuccessState(:final items):
      print('Success: $items');
    case ErrorState(:final message):
      print('Error: $message');
  }
}

void main() {
  print("=== APP STATE ===");

  updateUI(LoadingState());
  updateUI(SuccessState(["A", "B"]));
  updateUI(ErrorState("Gagal"));
}

Ringkasan & Best Practices

Ringkasan:

  • Sealed class digunakan untuk membatasi hierarki dan mendukung pattern matching
  • Base class digunakan sebagai dasar class yang hanya dapat di-extend
  • Final class digunakan untuk mencegah pewarisan dari luar

Best Practices:

  • Gunakan sealed class untuk state atau kondisi yang jumlahnya terbatas
  • Gunakan base class untuk membuat kerangka dasar program
  • Gunakan final class untuk class yang tidak ingin diubah atau diwariskan

Bonus Final Class MathUtils

MathUtils menggunakan final class karena hanya berisi fungsi utilitas dan tidak perlu diwariskan ke class lain.

Penggunaan final class bertujuan untuk memastikan bahwa class ini tidak dapat diwariskan sehingga fungsi di dalamnya tetap aman dan tidak diubah oleh class lain.

Fitur Final Class pada MathUtils:

  • Tidak bisa di-extend oleh class lain
  • Tidak bisa diimplementasikan
